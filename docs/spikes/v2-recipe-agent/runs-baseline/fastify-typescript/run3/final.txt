The recipe is at `.gantry/recipe.json`, and the dry-run says `ACCEPTED` with all examples passing.

**Stack:** Fastify 4 with TypeScript, and Prisma for the database.

**Listed:**
- **Routes (0):** there is no frontend in this repo.
- **Endpoints (5):**
  - `GET /`
  - `GET /health`
  - `POST /api/user/login`
  - `POST /api/user/signup`
  - `POST /api/post/create`
- **Tables (2):** `users` (Prisma `User`, mapped with `@@map`) and `Post`. The `Role` enum isn't a table, so it's left out.

**Not expressed generically:** I hard-coded the prefixes `/api/user` and `/api/post` in the rules for `src/routes/user.router.ts` and `src/routes/post.router.ts`. I did this because the recipe didn't connect `register(plugin, { prefix })` calls to the `fastify.post(...)` handlers inside the plugin functions. The `register` rule I tried matched the two calls in `main.ts` but produced no endpoints. A new plugin file or a changed prefix needs a new or edited rule.

The plugin endpoint rules also match only calls with two or three arguments, such as `fastify.post(path, options, handler)`. The `$$REST` form matched in `main.ts` but not the multi-line calls in the plugin files.
