The recipe is at `.gantry/recipe.json`, and the dry-run says `ACCEPTED`.

- **Stack:** Next.js app router with a Drizzle ORM schema (`pgTable`).
- **Routes (9):**
  - Under `/[locale]`: the home page, about, counter, dashboard, portfolio and `portfolio/[slug]`.
  - Also under `/[locale]`: the dashboard user-profile, sign-in and sign-up catch-all pages.
  - Route groups like `(marketing)` are stripped from the URLs.
  - `[locale]` stays as a dynamic segment, because the code doesn't give a fixed prefix.
- **Endpoints (1):** `PUT /api/counter`. It's the only exported HTTP handler in `src/app/api`.
- **Tables (1):** `counter`.
- **Rules:** one rule, `api-routes-fn`, matches nothing in this repo. I kept it because Next.js `route.ts` files can export handlers as `export async function GET`, and none do yet.
- **Not expressed:** nothing was missing.
