The recipe is at `.gantry/recipe.json`, and the dry-run says `ACCEPTED`. It lists 1 route, 7 endpoints and 6 tables.

- **Stack:** a Go backend using Gin, a Vue 3 frontend with vue-router, and Postgres migrations in `db/migration`.
- **Routes (1):** `/`. It comes from `frontend/src/router/index.ts`, which defines only the home route.
- **Endpoints (7), all in `api/server.go`:**
  - `POST /users`
  - `POST /users/login`
  - `POST /tokens/renew_access`
  - `POST /accounts`
  - `GET /accounts`
  - `GET /accounts/:id`
  - `POST /transfers`
- **Tables (6):** accounts, entries, transfers, users, sessions and verify_emails. The recipe reads them from the `CREATE TABLE` statements in `db/migration/*.up.sql`.

**Hard-coded route:** the route rule can't read a path out of the vue-router config. It emits `/` for that one file, so a second route added there would be missed.

**Not covered:** `main.go` registers the gRPC service and grpc-gateway, and mounts `/` and `/swagger/` on a plain `http.ServeMux`. I left those out because the gRPC and gateway routes aren't method plus path.
