The recipe is at `.gantry/recipe.json`, and the dry-run says ACCEPTED with all examples passing.

**Stack:** React Router with `react-router-auto-routes` file routing, an Express server, and Prisma.

**Listed:**
- **Routes: 30.** These are the files under `app/routes` with a default export, with their URLs built from the file paths:
  - Pathless `_auth`, `_marketing` and `_seo` folders are dropped.
  - `.` becomes `/`.
  - A trailing `_` on a segment is removed.
  - `$` becomes `*`.
- **Endpoints: 14**, all method `ALL`. These are the resource routes: files with a `loader` or `action` and no default export. They include `/robots.txt`, `/sitemap.xml`, `/resources/healthcheck` and the `auth` and `webauthn` routes.
- **Tables: 11.** These are the Prisma models in `prisma/schema.prisma`.

**Not expressed:**
- **Explicit file lists:** the route and endpoint rules name their files one by one, because I couldn't exclude layouts, `.server` files, tests and `+` folders with negated globs (`!…`). A new route file has to be added to those lists by hand.
- **`app/routes/admin/cache/sqlite.tsx`:** I included it in the endpoint file list, but the dry-run doesn't list it, so I treated it as neither a route nor an endpoint. I didn't check what it exports.
- **Express handlers in `server/index.ts`:** I left these out. They are middleware, static serving and a catch-all `app.get(/.*/)` that does a redirect. I didn't write a rule for them.
