I wrote the recipe to `.gantry/recipe.json`, and the dry-run says ACCEPTED with all examples passing.

- **Stack:** Fastify 4 with Prisma. The route files are plugins that `main.ts` mounts with `register(plugin, { prefix })`.
- **Endpoints (5):**
  - `GET /`
  - `GET /health`
  - `POST /api/user/login`
  - `POST /api/user/signup`
  - `POST /api/post/create`
- **Routes (0):** this repository is backend only, so there are no frontend pages.
- **Tables (2):** `User` and `Post`, read from `prisma/schema.prisma`. The `User` model has `@@map("users")` and `Post` has no `@@map`. I listed both under their model names (`User`, `Post`) and did not use the mapped name `users`.
- **Not expressed:** nothing.

One workaround: the single-pattern endpoint form `$R.$M($X, $$A)` failed on a three-argument call. I replaced it with an `any` of the two-, three- and four-argument forms. A route registered with five or more arguments would not match.
