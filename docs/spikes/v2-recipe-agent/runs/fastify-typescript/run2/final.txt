The recipe is at `.gantry/recipe.json`, and the dry-run says ACCEPTED with all examples passing. The listed endpoints and tables match what I read in the code.

- **Stack:** Fastify 4 with Prisma. Routers are registered with `server.register(router, { prefix })`.
- **Routes:** 0. This is a backend-only API with no frontend pages.
- **Endpoints:** 5.
  - `GET /`
  - `GET /health`
  - `POST /api/user/login`
  - `POST /api/user/signup`
  - `POST /api/post/create`
- **Tables:** 2. They are `users` and `Post`. The `User` model is listed under its `@@map("users")` name, and `Post` has no explicit name, so it keeps the model name.

Nothing in this repository was left out. Two things behave differently from the instructions:
- **Endpoint rule:** It uses an `any` of the two-argument and three-argument forms. The single `$R.$M($X, $$A)` pattern failed on the three-argument form.
- **Table rules:** The Prisma table rules are two text regexes, one for models with `@@map` and one for models without. A single regex couldn't use `@@map` where it exists and the model name otherwise.
