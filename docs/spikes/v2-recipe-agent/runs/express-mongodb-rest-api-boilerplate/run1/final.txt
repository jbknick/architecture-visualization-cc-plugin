The recipe is at `.gantry/recipe.json`, and the dry-run says `ACCEPTED`. It lists 22 of the 24 registrations in the code, so two are missing.

- **Stack:** Express with Mongoose (TypeScript, ESM), a domain-based layout with a `createXRouter()` function per domain.
- **Routes:** 0, since this is a backend-only API.
- **Endpoints:** 22 listed, including the `/docs/...` and `/openapi.json` ones and the `/health/live` and `/health/ready` checks.
- **Tables:** 7 listed, taken from the `model('Name', …)` calls: `User`, `ResetPassword`, `Verification`, `Media`, `EmailBudget`, `EmailOutbox` and `EmailWorker`. I used the model names, not the explicit `collection:` names such as `email_outbox`.

Two things are not captured:
- **`/auth/sign-out`:** it is registered as a chain, `router.route('/auth/sign-out').post(...).get(...)`. I added chain rules for this, but they matched nothing, so `POST /auth/sign-out` and `GET /auth/sign-out` are missing. I did not work out why.
- **Template-literal path:** `docs.get(\`/${filename}\`)` inside a `for` loop serves `/docs/swagger-ui.css` and `/docs/swagger-ui-bundle.js`. Its path is not a static string, so the dry-run reports it as unresolved.

Every route pattern also had to be written out for each argument count, up to four middleware arguments. A single variadic pattern did not match the longer calls. A route with more than four middleware arguments would be missed.
