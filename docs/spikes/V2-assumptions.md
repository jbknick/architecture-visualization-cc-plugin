## Plan changes recommended

1. Make M10's language interface independent of M8 (start after M7); only Go frameworks wait for M8.
2. Pin `@ast-grep/napi` 0.51.3, `@ast-grep/lang-go` 0.0.6 (and later `@ast-grep/lang-java` 0.0.7) in spec section 2; document the five prebuilt platforms.
3. Hashing: the language supplies `{ exact, shape, selfRefs, stmtCount }` and the embedding text; shared code computes all five hashes.
4. Go calls: require concrete-method local type inference; resolve interface calls to the interface method at high confidence; add name-based `implements` edges at low confidence; drop the helper binary from V2.
5. Recipes: add the generic helpers and router/mount output kinds; replace "matches at least one site" with example-based rule tests; score on held-out repos; ship Go pattern pitfalls in the discovery prompt.
6. M11: base config entries `{ repo, prefix? }` keyed by env var, origin, or same-origin prefix; track axios/ky instances; infer wrappers; a small constant evaluator for URLs; and NestJS/Express endpoint recipes before M11.
7. Fix the "no migrations" scope line against what `main` already does.
