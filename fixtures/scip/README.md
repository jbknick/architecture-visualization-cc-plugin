# SCIP index of `pnpm-turbo`

`pnpm-turbo.scip` is a SCIP index of `fixtures/pnpm-turbo`, made once with scip-typescript 0.6.2. It is test data for precise mode (`gantry index --scip`, spec section 11) and is not regenerated by any test or script. scip-typescript is not a dependency of this repo.

Produced from a copy of the fixture, in a directory with a neutral path (the index records the directory it was made in as `project_root`):

```sh
cp -R fixtures/pnpm-turbo /tmp/gantry-scip/pnpm-turbo   # without the nested .claude folder
cd /tmp/gantry-scip/pnpm-turbo
pnpm install --ignore-scripts
pnpm dlx @sourcegraph/scip-typescript@0.6.2 index --pnpm-workspaces --output <repo>/fixtures/scip/pnpm-turbo.scip
```

The install is only there so the packages of the workspace and their dependencies resolve; nothing it creates is kept. The index holds 23 documents (the paths are relative to the fixture), with no document text and UTF-16 positions; one document, `apps/web/src/routeTree.gen.ts`, is a file Gantry excludes.

If the files of `fixtures/pnpm-turbo` change, the index is stale for them and must be produced again with the command above.
